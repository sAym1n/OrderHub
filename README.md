 OrderHub — система учёта заказов интернет-магазина

Итоговый сквозной проект по дисциплине «Программирование на языке C# / Объектно-ориентированное программирование» (контрольные точки КТ 31 – КТ 39).

 Стек технологий
 .NET 8.0+ / C# 12
 Git и GitHub (разработка по веткам stage/` слиянием через Pull Request)

 Как собрать и запустить
1. Клонируйте репозиторий:

   git clone https://github.com/sAym1n/OrderHub.git
   cd OrderHub
   
2. Запустите консольное приложение:
   
   dotnet run --project src/OrderHub

## Реализованные этапы
Этап 1 (КТ 31): Приём и обработка заказов через List<T> (общий список), Queue<T> (очередь FIFO) и Stack<T> (история отмены действий LIFO).
Этап 2 (КТ 32): Двусвязный список LinkedList<T> для истории заказов клиента с быстрой вставкой нового заказа после текущего узла (AddAfter).
Этап 3 (КТ 33): Складской учёт на базе Dictionary<string, int> с безопасным чтением через TryGetValue и удалением обнулённых позиций через Remove.
Этап 4 (КТ 34): Три способа сортировки каталога товаров (IComparable<Product>, внешний IComparer<Product> и лямбда-выражение Comparison<Product>).
Этап 5 (КТ 35): Базовые LINQ-запросы (Where, OrderBy, Select) и немедленные агрегаты (Count, Any, All, FirstOrDefault).
Этап 6 (КТ 36): Группировка каталога по категориям через GroupBy с расчётом количества и средней цены в каждой группе.
Этап 7 (КТ 37): Соединение коллекций заказов и клиентов через Join и формирование отчёта «Топ-3 клиента» с помощью Take.
Этап 8 (КТ 38): Ленивый генератор заказов OrderStream на базе yield return с трассировкой пошагового выполнения.
Этап 9 (КТ 39): Собственная коллекция кольцевого буфера CircularBuffer<T> с реализацией IEnumerable<T> для поддержки foreach, LINQ и обратного обхода Reverse().
